# 🏥 CMS Hospital Quality Analysis
This project analyzes publicly available hospital data from the Centers for Medicare & Medicaid Services (CMS) to examine hospital characteristics and quality performance across the United States. The project demonstrates an end-to-end healthcare analytics workflow. 


## 🤖 Technologies
- Python
- Pandas
- Numpy
- Matplotlib
- Scikit-learn
- SciPy
- CMS Data API
- Jupyter Notebook
- VS Code
- Git/GitHub


## 🧩 Features
- Automatically retrieves the latest CMS hospital dataset through the CMS API
- Cleans and validates hospital quality data
- Explores hospital ratings across hospital types, ownership, states, and emergency services
- Create quality-performance features from CMS measure coutns
- Tests relationships between hospital characteristics and high hospital ratings
- Compares multiple classification models
- Generates reusable visualizations and processed datasets
